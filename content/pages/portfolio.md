# Portfolio

A selection of projects I've built and maintain.

## Crypto Dashboards

Real-time cryptocurrency monitoring dashboards using public exchange APIs. No backend, no database — just client-side JavaScript fetching and rendering live data.

- **Live Wallet Monitoring** — Track wallet balances across multiple tokens via Etherscan API
- **Stablecoins Dashboard** — USDC, USDT, and other stablecoin metrics
- **Exchange Trading Metrics** — Real-time pricing and volume across itBit, Gemini, Kraken, and more
- **Price Dashboards** — Multi-exchange price comparison for ETH, BTC, and altcoins

## inoTives Site

This portfolio site itself — a React SPA with:
- Markdown-based content authoring via Obsidian
- Build-time content indexing
- Infinite scroll blog with search and tag filtering
- Legacy dashboard embedding
