inoTives Sections

    01 · Concept

    A research notebook, at night.

    The inoTives brand is a working notebook for data and agents: dark paper, warm ink, and one bright signal color that only ever means “this is live, or this is where you are.” Everything else stays quiet so the data can be loud.

    02 · Color

    Color

    Eight core tokens carry the interface. Signal cyan and amber are the only saturated interface colors, and each has one job. Click a swatch to copy its hex.

    Core

    Contrast on paper

    WCAG 2 contrast ratios, computed live on this page. Body text needs 4.5:1; large text and UI marks need 3:1.

    Data palette

    For charts only, used in this order. Cyan leads because the first series is usually the one being asked about.

    Sequential · “heat”

    Low to high. Ends in amber so the peak reads as selected.

    Diverging · “balance”

    Negative pink, zero is the card color, positive cyan.

    04 · Formatting

    Numbers, dates and units

    One way to write each kind of value, everywhere: in copy, tables, tooltips and chart axes. The specifiers are d3-format and d3-time-format, so charts and text agree.

    05 · shadcn/ui

    Components through tokens

    shadcn/ui components read a fixed set of CSS variables, so a brand is applied once by mapping its tokens onto those names. Nothing inside a component hardcodes a color. Every component below is styled only through these tokens.

    06 · D3

    Charts in D3

    D3 has no theme, so the brand ships as a small helper: scales get the palette, axes get quiet ink and no outer ticks, gridlines sit one step above the card, lines are 1.75px monotone curves, and tooltips use the formatting rules above.

    Brand theme · switch off to see D3’s defaults

    07 · Three.js

    Scenes in Three.js

    3D follows the same notebook: the page shows through a transparent canvas, light is soft and slightly cool, solids are matte, and the signal cyan only appears as wireframe or glow on what is live. Labels are HTML (CSS2D), so they use the brand fonts and stay sharp.
